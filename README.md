# NeuroKey

Working desktop build. Fresh clone does not include models or API keys.
Run `SETUP.bat` once; it installs libraries and downloads the local models.

Full steps, in Uzbek: [YORIQNOMA.md](YORIQNOMA.md)

```bat
SETUP.bat
!NeuroKey.bat
```

Put `GROQ_API_KEY` in `.env` when Notepad opens. Free key: https://console.groq.com
